📊

Stateful Progress Checkpointing

Ingesting 50M Parquet rows or fine-tuning an LLM across 20 epochs? Stream cursor offsets via HeartbeatWithProgress. Every checkpoint replicates through Raft so if a worker or leader dies at 94%, the replacement worker resumes at 94% via LastProgress. 

resume = ctx.last_progress or {"offset": 0}
for batch in read_parquet(start=resume["offset"]):
    process(batch)
    ctx.heartbeat_progress({"offset": batch.end})
⏪

Time-Travel Step Replay (/replay)

When step 5 of an expensive data pipeline fails due to a downstream schema change, don't re-run 4 hours of upstream extraction. Deploy your fix and call /replay on step 5—upstream step outputs stay intact while downstream steps cleanly re-execute. 

curl -X POST http://localhost:8080/api/v1/workflows/etl-99/replay \
  -d '{"step": "transform-features"}'
⚡

Zero Determinism Tax (Standard Python & Go)

Forget workflow.Now(), workflow.SideEffect(), and dreaded NonDeterministicError crashes. Plexus-Flow evaluates workflow DAGs inside the Raft state machine—your workers are 100% standard Python or Go functions using Pandas, PyArrow, DuckDB, or PyTorch. 

@worker.activity("embed-chunks")
def embed(ctx: ActivityContext, data: dict) -> dict:
    # Call GPUs, UUIDs, clocks, or S3 freely!
    return {"vectors": model.encode(data["uri"])}

Fork-Join DAGs & Conditional Branching

Fan out across parallel feature-extraction branches with depends_on, dynamically skip branches using declarative when predicates on upstream step JSON outputs, pause on durable sleep timers, or block on human approval signals.

Automatic LIFO Saga Compensation

Provisioning cloud GPUs, staging Snowflake tables, and charging customer credits across microservices? Attach a compensating_action to any step. On downstream failure, Plexus-Flow automatically rolls back completed steps in reverse topological order. 

{
  "name": "allocate-gpu-cluster",
  "activity": "gpu.provision",
  "compensating_action": "gpu.teardown"
}
